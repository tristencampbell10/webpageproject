# webpageproject

A modern, responsive personal webpage and project showcase for Tristen Campbell, built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Project Showcase**: Overview of repositories including `webpageproject` and `photosalbum` with technical breakdowns and GitHub links.
- **Interactive Component Sandbox**: Live reactive state preview with customizable accent colors and variants.
- **Skills & Stack**: Detailed competency breakdown for frontend engineering and modern web tooling.
- **Direct Contact Channel**: Integrated inquiry form and direct email client shortcuts.
- **Port 3000 Ready**: Configured for AI Studio container environment.

## Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Development

```bash
npm install
npm run dev
```

Server binds to `http://0.0.0.0:3000`.
